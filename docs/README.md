# Documentation Guide

The documentation is organized around project milestones and evaluation concerns.

```text
docs/
├── step_1/
│   ├── objectives.md
│   ├── requirements.md
│   └── repository_setup.md
│
├── step_2/
│   ├── overview.md
│   ├── 2.0_ocr_pipeline.md
│   ├── 2.5_benchmarking.md
│   ├── 2.5.1_execution_architecture.md
│   └── paddleocr_notes.md
│
├── step_3/
│   ├── overview.md
│   ├── 3.1_text_metrics.md
│   ├── 3.2_critical_fields.md
│   ├── 3.3_faithfulness.md
│   ├── 3.4_real_data_evaluation.md
│   ├── 3.5_robustness.md
│   └── 3.6_error_analysis.md
│
├── architecture.md
│
└── evaluation/
    ├── evaluation_strategy.md
    ├── testing_strategy.md
    ├── production_risks.md
    └── final_evidence.md
```

The milestone documents describe what was implemented and why. The evaluation documents explain how the implementation should be interpreted against the assignment criteria.
