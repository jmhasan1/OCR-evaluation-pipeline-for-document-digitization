# Step 3.5 — Controlled Robustness Testing

## Purpose

The robustness experiment asks how measurable evaluation signals respond when known synthetic corruption is introduced into known reference text.

It does **not** claim to reproduce the true distribution of OCR errors in production.

## Experiment matrix

The current experiment uses:

```text
3 synthetic documents
× 6 degradation types
× 5 severity levels
= 90 cases
```

Severity levels:

```text
0.0
0.25
0.50
0.75
1.0
```

Degradation types:

- character substitution
- character deletion
- character insertion
- whitespace corruption
- punctuation corruption
- identifier corruption

## Evaluation layers

Each case is evaluated through existing metrics/components including:

- CER
- WER
- critical-field accuracy
- faithfulness CER
- changed-position information

Severity `0.0` is the deterministic control condition.

Expected control properties:

```text
CER = 0
WER = 0
field accuracy = 1.0
faithfulness CER = 0
```

## Why assignment data is excluded

The assignment documents do not provide authoritative synthetic references. Applying controlled corruption to them would not create meaningful ground-truth accuracy evidence.

The robustness experiment therefore remains restricted to the three synthetic development documents.
