# Step 3.1 — Text Normalization and OCR Metrics

## Normalization

`src/ocr_eval/normalization.py` performs conservative Unicode-aware normalization.

The purpose is to remove representation noise such as:

- Unicode compatibility differences
- inconsistent whitespace

Normalization must not silently repair meaningful OCR errors.

## CER and WER

`src/ocr_eval/metrics.py` calculates:

- Character Error Rate (CER)
- Word Error Rate (WER)

`src/ocr_eval/edit_distance.py` provides Levenshtein edit-operation counts:

- substitutions
- insertions
- deletions

## Identifier-sensitive behavior

For structured identifiers, punctuation and digits can carry meaning.

Example:

```text
Reference: Khasra 54/1
OCR:       Khasra 541
```

The missing `/` remains an error. Normalization must not turn the two values into an artificial match.

## Interpretation

CER/WER are text-level measurements. They should be combined with field-level and consequence-oriented analysis for document workflows.
