# PaddleOCR Notes

The project currently targets PaddleOCR 3.x and isolates it behind `PaddleOCRAdapter`.

The exact model/configuration will be recorded in the final report after the actual assignment documents arrive. Language selection should be based on the real documents rather than assumed in advance.

If PaddleOCR proves unsuitable for the employer's documents, the adapter boundary allows a second engine to be added without rewriting the evaluation layer.
