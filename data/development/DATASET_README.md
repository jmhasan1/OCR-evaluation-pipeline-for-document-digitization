# Synthetic OCR Evaluation Dataset

This dataset is for development and testing of the OCR evaluation pipeline while the employer-provided sample sale deeds are unavailable.

All names, numbers, addresses, dates, and property details are fictional.

## Documents
- doc_001: clean baseline
- doc_002: moderate difficulty with sample stamp region and annotation
- doc_003: stress test with seal/annotation and critical numeric fields

When the actual assignment documents arrive, place them in a separate `assignment/` dataset and do not represent these synthetic documents as the employer's samples.
